# Muse Beauty — редизайн сайта салона красоты

**Живой сайт → [bmxer32.github.io/musebeauty-redesign](https://bmxer32.github.io/musebeauty-redesign/)**

Переделка сайта салона красоты: восемь страниц, собственная вёрстка вместо
конструктора, галереи работ по направлениям и мобильное меню.

## Что где

| Путь | Что это |
|---|---|
| `index.html` и семь страниц направлений | сам сайт, отдаётся с корня |
| `assets/css`, `assets/js`, `assets/img` | стили, скрипты и изображения |
| `_muse/scripts` | разбор исходного сайта, подбор и раскладка фотографий, проверки |
| `_muse/raw` | сырые выгрузки: исходная разметка, карты блоков, тексты |
| `_muse/shots` | скриншоты проверок и сравнения «до/после» |
| `screenshots/` | съёмка страниц по разделам |

Страницы направлений: `hair`, `nails`, `lashes`, `brows`, `makeup`, `luxhair`, `contacts`.

`_muse/` — рабочая кухня проекта: она не участвует в отдаче сайта,
но по ней видно, откуда взялся каждый блок и каждая картинка.
